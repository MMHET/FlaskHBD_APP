# Country Guessing Game

A fun and interactive web application where users identify countries based on their flags. The game keeps track of scores and transitions to new levels as players progress.

## Features

- **Dynamic Flag Display**: Randomized flags with corresponding input fields for answers.
- **Score Tracking**: Earn 200 points for each correct answer. The page transitions to a new level when the score reaches 2400.
- **Real-time Feedback**: Input fields validate user answers instantly.
- **Background Music**: Background music starts playing automatically when the game page loads.
- **Responsive Design**: Built using Bootstrap for a seamless experience across devices.

## How It Works

1. On the landing page, click the "Play" button to start the game.
2. The game page loads with 12 flags displayed in a grid format.
3. Enter the country name in the input field below each flag.
4. Correct answers update the score in real time.
5. When the score reaches 2400, the page transitions to the next level with a smooth animation.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Backend**: Flask (Python)
- **Other Tools**: Jinja2 for templating, custom CSS for styling
